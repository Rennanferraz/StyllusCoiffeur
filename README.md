# 💈 Projeto de Construção do Site da Barbearia

### Checkpoint Final – Front-End I  
**Curso: DevMedia | Módulo: Front-End I**  
Este projeto tem como objetivo aplicar os conhecimentos adquiridos sobre HTML, CSS e JavaScript puro, desenvolvendo um site completo e responsivo para um negócio real da região do aluno.

---

## 🏢 Empresa Selecionada
**Styllu's Coiffeur – Unidade Masculina e Infantil**  
Localizada no bairro do Catete (RJ), a Styllu's é reconhecida pelo ambiente moderno e acolhedor, com serviços personalizados para o público masculino e infantil.

**Destaques do atendimento:**
- Cortes modernos, clássicos e infantis
- Barba com toalha quente e óleos hidratantes
- Espaço lúdico para crianças

---

## 🎯 Objetivos do Projeto

- Construir um site completo para uma barbearia real
- Aplicar conceitos de layout responsivo (Mobile First)
- Integrar funcionalidades com WhatsApp para agendamento
- Utilizar HTML5, CSS3 e JavaScript puros
- Cumprir os requisitos do wireframe e checklist propostos no curso

---

## 🗂️ Estrutura do Site

- **Header fixo:** com menu de navegação (âncoras internas)
- **Seção Hero:** imagem de impacto, chamada e botão “Agendar Agora”
- **Sobre a Empresa:** texto institucional com destaques
- **Tabela de Serviços:** cards com serviços e valores
- **Agendamento:** via formulário ou botão WhatsApp
- **Galeria:** imagens reais do espaço físico
- **Mapa:** embed do Google Maps com localização do salão
- **Rodapé:** com logomarca, informações de contato e redes sociais
- **Botão Flutuante:** WhatsApp acessível em todas as páginas
